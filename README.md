# Teresio Gassino — GitHub Pages Site

A static tribute site with real content, bilingual Italian/English text set in Merriweather, and scroll/load-triggered image animations. No build tools required.

## Structure
```
site/
├── index.html                      ← landing page
├── home.html                       ← full essay
├── logos.html
├── discorso.html
├── curriculum.html
├── galleria.html                   ← Foto
├── quercia.html                    ← hidden page, NOT in nav, linked from home.html text only
├── en/                             ← English counterpart of every page above, same filenames
├── css/style.css
├── js/animations.js
├── DECISIONS.md                    ← long-form reasoning behind the CSS
├── fonts/                          ← self-hosted Merriweather/Merriweather Sans .woff2 + subset.sh

├── sfondi/                         ← decorative/UI SVGs and favicons

    ├── discorso/                   ← thumbnails for the clump animation
    ├── galleria/                   ← Foto gallery images
    └── quercia/                    ← images for the hidden Quercia page
```

## Where things are written down
- **`css/style.css`** — one short comment per rule, saying what that rule does.
- **`DECISIONS.md`** — the reasoning, measurements and history behind those rules. The stylesheet points at it by number: `→ DECISIONS.md §37`.
- **`js/animations.js`** — comments stay inline, next to the control flow they describe.

Adding a rule that needs more than a line of explanation: line in the stylesheet, reasoning in `DECISIONS.md`, numbered after the last entry. Don't renumber existing entries — every number is referenced from the stylesheet. Retire one by marking it obsolete; don't delete it.

## Font
Merriweather (serif) and Merriweather Sans, self-hosted in `fonts/` as `.woff2` (SIL Open Font License, see `fonts/OFL-merriweather.txt`), loaded via `@font-face` in `css/style.css`. No Google Fonts request is ever made. Files come from the Fontsource npm packages (`@fontsource/merriweather`, `@fontsource/merriweather-sans`).

Weights present: Merriweather 300/400/700/900 + 400 italic, Merriweather Sans 300/400/700/800 + 400 italic. Merriweather 300 (serif light) is declared but unused; Sans 300 is used, by `.essay-subtitle`. Merriweather Sans has no 900 cut — the five sans page titles use 800.

Four faces load on a typical page: 139 KB total. All ten files are subset by **`fonts/subset.sh`**; re-run it against the Fontsource originals whenever those are replaced. The range covers Latin-1, Latin Extended-A, Greek, typographic punctuation, arrows and common maths symbols. Two characters used on the site fall back to a system font because neither Merriweather contains them: ↗ (U+2197) and ⤢ (U+2922).

## 1. Images
All content photos are WebP, sized at roughly 2× their CSS display width. Two Curriculum scans (the CFM diploma and the Cavaliere honour) exist twice: an on-page thumbnail at 800px and a `-full` version up to 1600px on the long edge, opened in the document viewer. `curriculum-fronte.webp` exists only at 1200px. `brevetto.webp`, `brevetto-2.webp` and `brevetto-3.webp` are the patent card's three rotation frames: all 800×615, so the card never reflows between them. Frame 1 is 65KB and frames 2 and 3 are 79KB and 83KB — a difference the card never shows, since the geometry is what holds it steady: the `width`/`height` attributes reserve the box before any file arrives, and frames 2 and 3 are absolutely positioned inside it. `images/creative.png` and every SVG in `sfondi/` are untouched.

Six images double as `og:image`/`twitter:image` sources as well as on-page thumbnails — `card-tecnigrafo`, `logos-pintori`, `curriculum-fronte`, `discorso/capellaro`, `teresio-tecnigrafo`, `galleria/foto-01` — each at least 1200px on the long edge. Quercia's `og:image` (`quercia/quercia-1-clump.webp`) is 630×415.

Every content image carries `width`/`height` attributes matching its real file dimensions, paired with `height: auto` in CSS.

No image uses `loading="lazy"`.

## 2. Layout notes

- **Header**: fixed, translucent gray nav bar (`rgba(220,220,220,0.68)` with a blur), content constrained to a centred `.nav-inner` (max-width `56.25rem`). "Teresio Gassino" links to the landing page. The bar hides on scroll down and reappears on scroll up. Below `67.5em` (1080px at a 16px default font) the links collapse into a burger menu on the right; tapping it animates open and the burger morphs into an X — tap again, tap a link, or tap outside to close. The bar stays visible while the dropdown is open, and the closed dropdown is `visibility: hidden` so it stays out of the tab order. The `<button>` sits **before** the `<nav>` in the markup so that Tab from the burger enters the menu it just opened, and the menu closes on `focusout` as well as on outside click, so the next Tab doesn't land under the open dropdown (`DECISIONS.md` §AE). Hovering a nav link shows an underline; only `.active` is bold.
- **Type scale**: every `font-size` is in `rem`, against `html { font-size: 100% }` — the reader's own browser setting. Padding, radii and borders stay in px. `body`'s `padding-top`, `main`'s `padding-bottom`, `.brand-signature`'s height, the nav breakpoint and the nav bar's own two max-widths all scale with the type. No `clamp()` yet. (`DECISIONS.md` §B)
- **Typefaces**: Merriweather (serif) for body text; Merriweather Sans for the nav, the footer, and every `.fonte` citation line. The five section-index pages (Index, Logos 27, Discorso, Curriculum, Foto) take a sans `<h1>`; Home and Quercia keep the serif title. Each of those five titles is followed by a `.page-subtitle` in serif italic.
- **Breakpoints**: six width thresholds, all in `em` — `35` / `37.5` / `40` / `43.75` / `50` / `67.5em` (560 / 600 / 640 / 700 / 800 / 1080px at a 16px default font). `em` and not `px` on purpose: in a media query it tracks the browser's default font size, so a reader who enlarges their text moves every threshold with it. Each rung belongs to one component — the ladder comment above `.skip-link` in `css/style.css` says which. Pick an existing rung before adding a seventh, and note that `max-width: 50em` is paired with `min-width: 50.0625em`: change one, change both. (`DECISIONS.md` §J)

- **Footer**: fixed gray bar, black text, Creative Commons logo then the credit line. The licence reads "Creative Commons salvo diversamente indicato" / "unless otherwise indicated" — the site reproduces third-party material (Banchelli's posts, pages from Piol and Sartor, the Quercia photos) that is quoted under attribution and is *not* CC-licensed, so the blanket claim had to be qualified; the longer statement sits at the end of `discorso.html`'s credits band as `.ritagli-nota`. Don't drop the qualifier when editing the footer. (`DECISIONS.md` §D, §I) On a landscape phone the bar is not fixed — it scrolls away with the page, full-bleed and square-cornered, and `main`'s bottom padding drops accordingly.
- **Translucent chrome**: the nav, the footer, the language pill, the burger dropdown and `.ritagli-band` are translucent over the page and use `backdrop-filter`, declared both prefixed and unprefixed. An `@supports not (...)` block gives browsers without it an opaque equivalent; `.ritagli-band`'s fallback is a solid `#4C4C4C`. (`DECISIONS.md` §E)
- **Side-by-side image + description** (Logos 27, Curriculum): `<figure class="reveal-img side">` puts the image and its `<figcaption>` next to each other, stacking on mobile. Modifiers: `from-right` flips the image to the other side, `align-top` aligns the text to the top of the image. `crop-top` (crop from the top instead of the centre) is a plain `.reveal-img` modifier and is also used on its own in the Foto grid.
- **Image badges** (Logos 27, Curriculum): every linked image carries a 12px pill badge in the bottom corner — PDF / Link / Enlarge / Espandi lista, via `.img-badge` — plus a darkening overlay on hover and on `:focus-within`. The patent card's badge is the one that isn't a link: its trigger is a real `<button>`, because it opens a dialog rather than going anywhere.
- **Clump animation** (Discorso, Quercia): the thumbnails in `.clump-stage` slide in and land clustered on page load, in pure CSS. Discorso uses six photos at 370×240px entering from different sides, with all the page's text below in one dark translucent `.ritagli-band`. Quercia reuses the mechanism for two photos at 630×415px above its own shorter `.ritagli-band`; both enter from the right, staggered by their inline `animation-duration`/`--delay`. Below 800px the clump becomes a plain vertical stack. (`DECISIONS.md` §36, §40)
- **Document viewer** (Discorso's two Banchelli photos, Curriculum's diploma and onorificenza, both Quercia photos): a native `<dialog>` (`.doc-viewer-overlay`) opened by any `.doc-viewer-trigger`. It enlarges the image and, where a transcript exists, shows a "Versione testuale" pill (`.doc-viewer-toggle`) that swaps the image for text cloned from a `<template>`. While the scan loads the image sits at `opacity: 0` behind a spinner; both `onload` and `onerror` clear it, so a file that never arrives shows the broken-image placeholder and its `alt`. The transcript button still works in that case. Triggers with a transcript and **no** `data-doc-src` open straight into text with the toggle hidden — that is how Curriculum's "Espandi la lista" works. The dialog's `aria-label` is swapped per trigger and restored from the authored default, since one dialog now serves two different things.
- **Per-image reveal** (Home, Logos 27, Curriculum, Foto, Quercia): each image fades or slides in as it scrolls into view, via `observeReveal(selector)` in `js/animations.js` — one `IntersectionObserver` helper called twice, for `.reveal-img` (slide in from a side) and `.essay-anim` (rise and fade, Home only). The two classes are separate: `.essay-anim` is applied per element and skips the title, epigraph and closing source note.
- **Foto grid hover**: once a thumbnail's entrance reveal finishes, `initGalleryReveal()` adds `.settled` and control passes from the entrance `animation` to a `transition`. On `hover: hover` + `pointer: fine` devices, hovering scales the image to 1.5× inside its card and fades in a caption gradient (`.gallery-caption`) carrying the photo's `data-caption`. The caption also shows on `:focus-within`, and under `@media (hover: none)` it is always on.
- **Lightbox**: a native `<dialog>` opened by any `.lightbox-trigger` button, each wrapping an `<img>` and carrying a `data-caption` shown under the enlarged photo. Used on the Foto grid and the two standalone photos on Home.

## 3. When something breaks
- **If `js/animations.js` fails, the content still shows.** The reveal animations start at `opacity: 0`, gated behind a `.js` class the inline `<head>` script adds. `animations.js` sets `window.__animsReady = true` as the **last** statement of its `DOMContentLoaded` handler; the inline script checks that flag on `load` and swaps `.js` back to `.no-js` if it is missing. Degraded outcome: no animations, everything on screen. **That promise is a real constraint, not a slogan:** anything whose only route is a `<button>` has to have a `.no-js` route too, which is why `.no-js .doc-list-full[hidden]` unhides Curriculum’s complete patent list — before it existed only the card’s own eight were reachable, and the 33 held nowhere else were not. The *content* is the promise, not the controls: the rotator `<button>` stays in the tab order doing nothing on this path, accepted on purpose and only because the list it would have opened is now printed below it — don't re-fix it from CSS, which cannot set `disabled`/`inert` (`DECISIONS.md` §O). **If you add an `init*()` call, add it above that flag.**
- **If a document scan fails to load**, the viewer stops pretending to load it — see "Document viewer".
- **Printing works, but only because a `@media print` block makes it work.** Without it the site prints almost nothing, and the reason is structural rather than cosmetic: the palette is light-on-dark and browsers don't print background colours, and every image and essay paragraph starts at `opacity: 0` waiting for an `IntersectionObserver` that printing never triggers. **A dialog open at print time prints instead of the page** — gated on `body:has(dialog[open])`, so with none open the sheet is untouched; `position: static` on the dialog looks removable and is not (`DECISIONS.md` §AB). The block inverts the palette, cancels every entrance state, unpins the fixed chrome (the footer prints once at the end — it carries the licence line; the nav, language pill, skip link, burger and badges are dropped), and opens `.text-window` and `.clump-stage` to their natural height. **Two traps if you edit it:** an A4 sheet is ~673 CSS px of printable width, so every narrow-layout rule below `50em` is already in force while printing — the print layout is the phone layout unless told otherwise; and the clump photos are children of `.clump-anchor`, so hiding the anchor hides all six. (`DECISIONS.md` §M)
- **Back navigation restores your reading position.** The site does this itself rather than leaving it to the browser: `history.scrollRestoration` is `manual`, and `initScrollMemory()` in `js/animations.js` saves a position per history entry in `sessionStorage`, restores it on Back (fresh load, bfcache resume, and same-document Back alike), then re-asserts it every frame for up to 1.2s so a late scroll from a fragment, a font reflow or a cancelled animation cannot take it away. The window ends early once the page is stable, and instantly on any touch or key press. `scroll-behavior: smooth` is held off `html` for the duration; in-page anchor jumps are still smooth. The scroll listener flushes on **both** edges of its 500ms throttle, so a position reached at the end of a smooth jump is still recorded. If `animations.js` fails to load, the inline `<head>` script puts `scrollRestoration` back to `auto`. (`DECISIONS.md` §G, §H, §N)

## 4. Accessibility & SEO
- Every page has a self-referencing `<link rel="canonical">` alongside its `hreflang` alternates. The two homepages canonicalize to `https://teresioweb.github.io/` and `.../en/`, not the `/index.html` form.
- The lightbox and the document viewer are real `<dialog>` elements opened with `.showModal()` — focus trapping, Escape-to-close and top-layer stacking are native. A small Tab handler patches one Chromium quirk on each. Their triggers are real `<button>`/`<a>` elements.
- **`color-scheme: dark` on `:root`** gives the page scrollbar and the three scrollable dark panels (`.text-window`, `.doc-viewer-scroll`, `.doc-viewer-text`) dark UA chrome. The print block re-declares it as `light` **on `:root`, not `html`**: the two match the same element, but `:root` scores as a pseudo-class and wins. (`DECISIONS.md` §L)
- **Two link colours, because `.text-window` tints its own background.** `--link: #205C8B` on `.color-band` is tuned against the bare card colour; `.text-window` lays `rgba(0,0,0,0.06)` over it and scopes its own `--link: #1A4F78`, which clears AA on all four card colours (4.88 pink to 6.27 yellow). Same reason its body text is `#4A4A4A` and not `#555` (§48). **A new `.text-window` on any card is already covered; retuning `.color-band`'s `--link` means retuning this one too.** (`DECISIONS.md` §L)
- **Colour-coded ritagli.** The six photographed excerpts on Discorso each carry a `.visually-hidden` transcription (clip technique, so it stays in the accessibility tree). Each opens by naming its own colour and which numbered paragraph it points to, since the colour link between excerpt and source paragraph is otherwise purely visual. **The transcription is a sibling of the `<a>`, not a child of it** — as a child it becomes part of the link's accessible name. In print this pairing is the one place on the site that forces background colour (`print-color-adjust: exact` on `.hl`), with an underline as the colourless fallback.
- **Heading structure.** On Logos 27 the opening line of each figcaption is a real `<h2>` with `font: inherit`. Curriculum's bold runs sit mid-sentence, so each of its four figures carries a `<h2 class="visually-hidden">` naming the document instead. Foto has no per-photo headings. (`DECISIONS.md` §A)
- **Real lists.** The four articles on Logos 27, the patents on Curriculum and the four source credits on Discorso are `<ul>`, with the `>` marker drawn as a `::before`. The first two carry `.doc-list`; Discorso’s is the plain `<ul>` inside `.ritagli-band`, whose own marker rule targets `li` — the rights note stays a `<p>` and is excluded by structure rather than by a `:not()`. **If a run of items already draws its own marker, it is a list; give it the markup.** Curriculum's card shows **eight** patents under a centred `.doc-list-intro` naming the slice ("Brevetti degli anni Logos" / "Patents of the Logos years") — and the "⤢ Lista" badge opens the complete **41** in the document dialog: four lists (14 unlabelled, 7 with Natale Capellaro, 13 with other co-inventors, 7 after Olivetti) split by three `<h3 class="doc-list-heading">` sub-headings, centred, with the first group deliberately unlabelled. Eighteen entries are multi-country families, listed once under the US document with the other jurisdictions' codes in brackets (24 codes; §R still says sixteen and 22, from before §AG added the two FR cross-references) — **codes appear only inside `.doc-list-full`**, not in the card's box, so each group is announced as its own list with its own item count. **The eight are selected by patent number in the build, and the cut is editorial, not chronological.** The run ends at the *mechanical bit* (3,363,837) and excludes 3,390,929, "Soundproof cover for an office machine" — a cover, not calculating mechanism. No date tells you this: those two share a priority year (1966) *and* a grant year (1968), and only the full priority dates part them, 9 Feb against 7 Apr 1966. **Don't restate that boundary as the reason.** An earlier "filed between 1964 and 1968" was exactly such a back-derived range, and it outlived the display change that made it false (§AF swapped grant years for priority years; the card now shows 1963–1966). This is why `.doc-list-intro` naming the slice is permanent: an editorial judgement is not inferable from any column. (`DECISIONS.md` §O retirement note, §AF)
- **The complete list is a `[hidden]` div, not a `<template>`.** Every other transcript here is a `<template>`, which is right for them — they duplicate a scan that is already on the page. This one is the only copy of 33 of its 41 entries, and `<template>` content cannot be revealed by a stylesheet, so printing would have dropped the page from 41 patents to 8. It lives in `<div id="text-brevetti-completi" hidden>` instead: out of the accessibility tree and the tab order on screen, cloned into the dialog by `cloneSource()`, and unhidden **as an appendix after `</main>` on both paths where the dialog cannot exist** — the print block, and `.no-js`, since both of its triggers are `<button>`s and without JS those 33 entries would otherwise be unreachable rather than merely hidden. **If you add a transcript, use a `<template>` unless it is the only copy of something.** (`DECISIONS.md` §O)
- **Two expand controls, styled differently on purpose.** The badge over the drawing is primary and always visible; the copy at the end of the list *inside* `.text-window` is deliberately redundant, for a reader who scrolled looking for more, and is a plain underlined link so the two do not compete. Both are hidden in print. (`DECISIONS.md` §P)
- **`.menu-toggle` is a 26x20 glyph in a 26x24 target box**, bars at `top: 2 / 11 / 20`. SC 2.5.8 measures the target, not the drawing, so the box clears the floor while the glyph keeps its size. The top rule sits exactly on the cap height of "Teresio Gassino", and that shared edge is what makes the nav read as aligned. **If you resize this, keep the top rule on the brand's cap height** — matching centres is not enough. (`DECISIONS.md` §S)
- **The patent card's trigger is a `<button>`, and `.side-row > a, .side-row > button` styles both.** That selector carries `overflow: hidden`, `position: relative`, `border-radius` and the hover overlay — the frame the entering image slides out from behind. **Swap an element's tag and re-read every selector that was styling it.** (`DECISIONS.md` §T)
- **In-page fragment links are repaired by `initFragmentLinks()`** — the coloured words on Discorso, the footnotes on Home, the skip link on all 14 pages. A link whose target the document is already at navigates nowhere, so the handler re-performs the scroll itself. It fires **only** when `location.hash` already equals the href, and touches neither `history.state` nor the hash, because `initScrollMemory()` keys history entries by a `twKey` it stores there. **When testing anchors, use a real click:** a synthetic `element.click()` sets the hash without performing the fragment scroll, which counterfeits this exact bug. (`DECISIONS.md` §W)
- **Dialogs focus themselves on open, not their close button.** Programmatic focus on a `<button>` leaves Safari matching `:focus-visible`, which painted a keyboard ring on the X when a touch user opened a lightbox. The dialog is a container with `outline: none`, so focusing it shows nothing, announces its `aria-label`, and leaves the first Tab landing on the X with a proper ring. **Don't "fix" a stray focus ring by removing it.** (`DECISIONS.md` §V)
- **The burger's two transitions use direction-specific easing.** With one shared `ease` the bars converged as fast as they rotated and read as a single blurred bar mid-animation. Opening, rotation leads and convergence lags; closing is the mirror. (`DECISIONS.md` §V)
- **Everything in a `.side-row` is cropped to 4/3** by `.reveal-img.side img`, whatever its natural proportion. A wrapper with a different `aspect-ratio` leaves a strip of card showing under the image and pushes the badge off the shared alignment. (`DECISIONS.md` §V)
- **Hidden section headings** carry the structure of the two long pages: four on Home, two on Discorso, all `<h2 class="visually-hidden">`, all costing zero layout. Galleria and Quercia are too short to need any. (`DECISIONS.md` §U)
- **Never set the `transition` shorthand on a `.reveal-img img`.** It replaces the shared `opacity 0.8s, transform 0.8s` rather than adding to it, and the entrance slide silently stops animating. Use longhands or none. (`DECISIONS.md` §T)
- **`.text-window` sets `color-scheme: light`.** The page is `dark` at `:root`; this box is a light surface on a pastel card and needs a light scrollbar. `color-scheme` describes a surface, not a site. (`DECISIONS.md` §L, §P)
- **Anything reading `scrollTop` from a scroll container must clamp both ends.** iOS Safari rubber-bands past the start, so `scrollTop` goes negative — Chromium never does, and a missing `Math.max(0, …)` in the rotator left the patent card permanently blank on iPhone while passing every desktop test. The rotator now asserts its whole class set on each event rather than tracking a cached index, so a desync repairs itself on the next scroll. (`DECISIONS.md` §Q)
- **Patent card rotator.** Scrolling the eight-item box cross-fades the card between three patent scans (`.patent-rotator`, `initPatentRotator()`). Frames 2 and 3 carry an inert 1×1 gif as `src` and the real file in `data-frame-src`, and are given the real `src` on an idle callback after `load`, so they stay off the critical path; the placeholder is there because an `<img>` with no `src` at all is invalid HTML, and it is never painted, since both frames sit at `opacity: 0` until the swap. They carry `alt=""` so the trigger's accessible name doesn't change with the picture. The rotation is off entirely under `prefers-reduced-motion`, and off below 60px of scroll range. (`DECISIONS.md` §O, §X)
- Decorative elements — the burger icon's bars, ornamental images — carry empty `alt=""` and stay out of the accessibility tree.
- The lightbox's enlarged `<img>` has `alt=""`; its `aria-live` caption is what announces the photo.
- **Structured data on all 14 pages, as one connected graph.** Every page carries a JSON-LD `@graph` referencing shared `@id`s: `#teresio` (the `Person`, defined in full on the two landing pages, `sameAs` the Italian Wikipedia article and Wikidata `Q103831208`), `#logos27` (a `Product`, `sameAs` Wikidata `Q17637386`), `#quercia`, and `#website` per language. Section pages are `CollectionPage`/`ImageGallery`/`WebPage` nodes that are `isPartOf` their site node and `about` the person. Italian and English pages share the same `#teresio` id. (`DECISIONS.md` §F)
- `robots.txt` points to `sitemap.xml`, which lists all 14 pages with their `hreflang` relationships.

## 5. English version (`/en/`)
Every Italian page has an English counterpart at the same filename under `/en/` — `curriculum.html` ↔ `en/curriculum.html`, including the hidden `quercia.html`.

- **Shared assets, one copy.** The English pages reference the same CSS, JS, fonts and images as the Italian ones, via **absolute paths from the domain root** (`/css/style.css`, `/images/...`). The Italian pages use relative paths (`css/style.css`).
- **`hreflang` tags** in every page's `<head>`, both languages, pointing to the counterpart.
- **Canonical link targets.** Nothing links to `index.html` in its `/index.html` form: the brand link uses `./` on Italian pages and `/en/` on English ones, and the language switcher uses `/` and `/en/`.
- **Language markup.** Italian titles, institution names and phrases inside the English pages carry `lang="it"` — including the Italian terms left untranslated inside the hidden transcripts. The Italian pages likewise mark their French and German quotations.
- **Language switcher**: a small pill sits just right of the nav bar on desktop (`.lang-link-desktop`, `position: fixed`, outside `.nav-inner` but inside `.site-nav`, whose `backdrop-filter` makes it the pill's containing block), positioned from the bar's own geometry: `calc(50% + min(29.6875rem, 50vw) + 12px)` — half the bar's max-width, in the same unit. **Change the bar's max-width and this moves with it.** (`DECISIONS.md` §AA) Below the nav breakpoint it hides and the same link appears as the last item in the burger dropdown (`.lang-link`), flag icon plus label. Both are plain links to the sibling page — no JavaScript.
- **Two flag icons** in `sfondi/`: `flag-it.svg` and `flag-gb.svg`, small hand-drawn SVGs, not emoji.
- **Extra footnote in the English essay.** `en/home.html` has an additional footnote, (**), giving background on Natale Capellaro. It does not exist in the Italian version.
- **Titles of works** stay in their original language with an English gloss in quotes — *Il sogno di un'impresa* ("The dream of an enterprise") — throughout Logos 27, Curriculum and Discorso.

## 6. Deliberate choices
Things that look like omissions on a quick pass and are not:

- **Colour carries meaning only on Discorso**, where each highlighted quote is tied to the excerpt it cites. It is not a site-wide system.
- **`target="_blank"` is for external sites and for PDFs and full-resolution scans only.** Internal links stay in the same tab.
- **Quercia has no `.page-subtitle`**, unlike the other five section pages.
- **`.lightbox-close`, `.lightbox-prev` and `.lightbox-next` carry `z-index: 1`.** `.lightbox-content` is `position: relative` and later in the DOM, so without it the photo paints over all three and a portrait phone loses prev/next entirely. (`DECISIONS.md` §AD)
- **The lightbox sizes itself by shrinking its gutter, not its photo.** `--lb-pad-x: min(5%, 40px)` on `.lightbox-overlay`; the photo takes `max-width: 100%` of what's left. Percent, not `vw` — `vw` counts the scrollbar. In `max-height`, `calc(100vh - …)` and never `100%`: a percentage against the auto-height container is indefinite and silently voids the cap. (`DECISIONS.md` §AD)
- **`--lb-chrome` is the counter and caption stacked under the photo.** It does three jobs from one number: the photo's `max-height` subtracts it, and both prev/next and the loading gear shift up by half of it so they land on the photo's middle rather than the column's. Never give the gear a fixed offset — between photos the box still holds the previous one and only a relative anchor tracks it. (`DECISIONS.md` §AD)
- **The gallery lightbox and the document viewer both show the same loading gear**, from two different code paths: the viewer sets it in `initDocViewer()`, the lightbox in `initLightbox()`'s `showIndex`. The lightbox one carries an extra `complete && naturalWidth` guard, because prev/next can re-show an image the browser already has and a `src` that doesn't change fires no `load`. (`DECISIONS.md` §AB)
- **Merriweather 300 is declared and unused.** Sans 300 is used; the serif light face is never requested by any page.
- **`figcaption` sits inside `.side-row`, not as a direct child of `figure`.** Invalid HTML — 16 Nu validator errors across Logos, Curriculum and their English pages — and left that way deliberately. Three attempts to correct it failed. **Don't start a fourth without reading `DECISIONS.md` §AC first.**
- **The nav bar's max-width is in rem, unlike every other box on the site.** It holds text that scales, so it scales too. (`DECISIONS.md` §AA)
- **Foto's grid is not a `<ul>`** and has no per-photo headings.
